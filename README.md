# A股实时行情与K线查看器 (Stock Viewer)

基于 Vue 3 + TypeScript + Vite + Tailwind CSS + Pinia + KLineChart 构建的轻量级专业 A股行情与K线看板。

## ✨ 特性

- ⚡️ **实时行情推送**：基于腾讯实时行情接口，支持 3s 定时轮询，买卖五档盘口、涨跌停、现价、涨跌幅、换手率、市盈率等指标完整呈现。
- 📊 **专业金融级 K线**：集成 `klinecharts` v10，支持分时(1m)、5分、15分、30分、60分、日K、周K、月K多周期无缝切换。
- 🎯 **开箱即用指标库**：
  - 主图：MA (均线)、EMA (指数移动平均)、BOLL (布林带)
  - 副图：VOL (成交量)、MACD、KDJ、RSI
- 🔍 **股票智能检索**：集成东方财富联想搜索 API，支持按股票代码、中文名称、拼音首字母搜索并一键加入自选。
- 💾 **自选股持久化**：自选股列表通过 `localStorage` 自动同步与去重，默认内置：**贵州茅台、宁德时代、比亚迪、中芯国际、平安银行、德赛西威、芒果超媒、三一重工**。
- 🎨 **专业暗黑风格**：红涨绿跌，符合中国 A股交易视觉习惯。
- 🔋 **超轻后台常驻**：基于生产预览构建（Vite preview），内存占用仅 ~25MB，CPU 接近 0%。

---

## 🚀 运行方式

项目默认服务端口为 **`30413`**（源自芒果超媒 `300413`，避开常用端口且符合 TCP 端口 0~65535 规范）。

### 1. 常驻后台运行（推荐，日常盯盘使用）

生产预览模式常驻后台，不占终端、关闭终端会话不退出：

```bash
# 启动后台常驻（自动构建并启动后台进程）
pnpm run start:bg

# 查看运行状态与 PID
pnpm run status:bg

# 实时查看运行日志
pnpm run logs:bg

# 停止后台服务
pnpm run stop:bg
```

启动后在浏览器打开 **`http://localhost:30413`** 即可使用。

### 2. 前台开发模式（代码开发与调试）

```bash
# 启动开发服务器（支持热更新）
pnpm dev
```

## 🛠 数据源架构

- **实时盘口 & 现价**：腾讯财经接口（原生 GBK 解码，支持批量高频拉取，含五档买卖深度与涨跌停价）。
- **多周期 K线**：
  - 分时 (1m)、日K、周K、月K：腾讯官方前复权接口（`web.ifzq.gtimg.cn`，低延迟无拦截）。
  - 5m、15m、30m、60m：新浪财经分钟K线接口。
- **股票代码联想搜索**：东方财富代码/拼音/汉字检索接口。
